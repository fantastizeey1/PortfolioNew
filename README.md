# Portfolio Website

This is a personal portfolio website built with Next.js, showcasing my projects, skills, and experience.

## Technologies Used

- [Next.js](https://nextjs.org/) - React framework for building server-side rendered and static websites.
- [React](https://reactjs.org/) - A JavaScript library for building user interfaces.
- [Tailwind CSS](https://tailwindcss.com/) - A utility-first CSS framework for rapid UI development.
- [Framer Motion](https://www.framer.com/motion/) - A React library for creating animations.
- [Aceternity UI](https://ui.aceternity.com/) - A collection of UI components for React.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Performance Optimizations

This project has been optimized for performance by implementing the following:

- **Next.js Image Optimization:** All images are served in modern formats like WebP and are lazy-loaded by default.
- **Dynamic Component Loading:** Heavy components are loaded dynamically to reduce the initial JavaScript bundle size.
- **Component-Level Code Splitting:** Code is automatically split at the component level, so only the necessary JavaScript is loaded for each page.
